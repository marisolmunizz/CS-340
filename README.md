How do you write programs that are maintainable, readable, and adaptable?

When writing programs, I like to start with a basic framework and gradually build on it as I go. I focus on getting the main functionality working before going back to review the smaller details. As I run the code, I check for any obvious bugs and make adjustments when necessary. This is similar to how I approach writing essays, where I start with a rough draft and continue improving it until I have a final version. For the CRUD Python module, this approach helped me develop the main database functions before connecting them to the dashboard.

What were the advantages of working in this way?

The biggest advantage of this approach is that it allows me to focus on the overall goal without overthinking every detail in the beginning. By starting with the main structure and making improvements afterward, I can see how everything works together. It also makes troubleshooting easier because I can address problems as they appear rather than trying to perfect everything at once.

How else could you use this CRUD Python module in the future?

The CRUD Python module could be reused in other projects that require communication between a Python application and a MongoDB database. Since the module handles creating, reading, updating, and deleting records, it could be adapted to manage different types of information. For example, a similar module could be used for customer records, inventory systems, or other applications that require database access.

How do you approach a problem as a computer scientist?

When approaching a problem, I like to identify the main requirements and work toward meeting them before focusing on smaller details. For the Grazioso Salvare project, I used the project requirements as a guide to make sure the database and dashboard provided the necessary functionality. When I encountered bugs or unexpected results, I tested different solutions and adjusted the code until I could move forward. This helped me stay focused on the overall purpose of the project.

How did your approach to this project differ from previous assignments in other courses?

This project was different because the earlier assignments were building toward one complete application. Instead of focusing on a single task, I had to consider how the database, Python module, and dashboard would work together. My main focus was making sure the overall application had a good flow and that each component could communicate properly. Once the main functionality was established, I could focus on smaller improvements and preparing everything for the final submission.

What techniques or strategies would you use in the future to create databases to meet other client requests?

In the future, I would begin by reviewing the client’s requirements and identifying what the database needs to accomplish. From there, I would build the main structure and test its functionality before making smaller adjustments. I would also make sure the database could be accessed by the application and that the information being retrieved was accurate. This approach would help me stay organized while allowing room for changes based on the client’s needs.

What do computer scientists do, and why does it matter?

Computer scientists develop programs and systems that help solve problems. Sometimes these programs automate tasks to make people’s jobs easier, while other times they provide access to information or services that people might not otherwise have. I think this work matters because technology can improve efficiency, make information more accessible, and help people accomplish things that would otherwise require more time or effort.

How would your work on this type of project help a company, like Grazioso Salvare, to do their work better?

The dashboard developed for Grazioso Salvare helps organize and present information about rescue dogs that may qualify for training. Instead of manually searching through large amounts of shelter data, users can filter the information based on different rescue categories and view the results through tables and charts. This makes it easier to identify potential candidates and allows the organization to spend less time searching through records and more time focusing on its rescue training efforts.
